## 2. 假设(每条含依据与后果)

- **A1 直线飞行/欧氏平面**:无其他障碍(问题3 才引入禁飞区)。依据:题目只给坐标与速度。后果:路径长度为折线段欧氏长度;若实际有建筑物绕行,总时长会被低估,见局限。
- **A2 多次巡检可连续或拆分**:同一点的 k 次巡检可在同一机一次到达时连续完成(每次计 5 min),也可由不同机在不同时刻完成。依据:原文"从不同方向、不同高度或**不同时间**获取信息"表明只约束总次数与可达性。后果:任务可建模为 M 个独立节点(重合坐标),调度自由度最大;敏感性分析中讨论"必须间隔"的变体。
- **A3 时间基准**:8:00 = t=0;9 h 上限 = 540 min;起飞、降落耗时 0;续航无限。依据:题目原文。
- **A4 服务时间计入停留**:巡检 5 min 内无人机视为静止,不产生飞行距离。

## 3. 问题1.1:下界与 Nmin 的证明结构

### 3.1 总工作量分解

任意调度中,总工作量 = 服务总时间 + 飞行总时间:

$$T_{busy} = T_{srv} + T_{fly}, \qquad T_{srv} = s \cdot M = 5M \ (\text{min})$$

若 N 台机均在 540 min 内完成,则总工时 ≤ 540·N,故对**任何有效下界** LB ≤ T_fly 有:
**N 可行 ⇒ 5M + LB ≤ 540N。**

### 3.2 飞行时间的有效下界(严格可证)

记 d_(1) ≥ d_(2) ≥ … 为各点到基地距离的降序。以下每条都是任意可行调度的必要条件,推导要点:

- **LB1(最远点往返)**:服务最远点 i* 的那台机至少从基地到达 i* 再返回,该机路线长 ≥ 2d_(1),故 T_fly ≥ 2τ·d_(1)。
- **LB2(均值)**:每台机路线长 L_r ≥ 2·(r 内最远距离) ≥ 2·(r 内各点距离的均值),对 r 求和得 T_fly ≥ (2τ/n)·Σ d_i。(注:文献中容量受限 VRP 的 (2/N)Σd_i 界依赖"每车点数≤N",本题无载客限制,不成立,不采用。)
- **LB3(最远两点)**:设 a,b 为距离最大的两点。若同机,该机路线 ≥ 首尾相接的 {0,a,b} 最小回路 = d_a+d_b+|p_a−p_b|;若异机,两机合计 ≥ 2d_a+2d_b。由三角不等式 |p_a−p_b| ≤ d_a+d_b,恒有 T_fly ≥ τ·(d_a+d_b+|p_a−p_b|)。
- **LB4(鸽笼,N≥2)**:N 台机、N+1 个最远点必有两点同机(或同被某机服务),同上得
  T_fly ≥ τ·min_{a<b∈Top(N+1)} (d_a+d_b+|p_a−p_b|)。
- **LB5(非空路线,N≥2)**:每台机均承担任务时,除服务最远点的机(≥2d_(1))外,其余 N−1 台机各至少服务一个点,其路线长度下界之和不小于 2×(最小的 N−1 个距离之和):
  T_fly ≥ 2τ·(d_(1) + Σ_{j=n−N+2}^{n} d_(j))。

取 **LB(N) = 5M + τ·max(LB1…LB5)**(其中 2 倍已含在各式内,代码中以长度计),得

$$N_{\min} \ge N_{LB} := \min\{N : LB(N) \le 540N\}.$$

**关键诚实声明**:这些下界只利用了"距离/几何端点"信息,未计入"必须覆盖所有 n 个点"的路径总长,因此对 N≥2 是宽松的。本题"理论最小值"的完整证明策略是:
1. 下界证明 N ≤ N_LB−1 不可能;
2. 构造 N_min 台机的可行调度(求解器输出,经独立校验脚本逐项复核)。
若构造的 N_min > N_LB,则如实报告 N ∈ [N_LB, N_min] 中的证明缺口,并用"对 N_min−1 的多起点、长时限搜索无法找到 ≤540 min 的解"作为不可行性的经验证据(不是严格证明,文中明示)。

## 4. 问题1.2:min-makespan VRP 模型

### 4.1 数学规划形式(记法用任务节点)

任务集 J={1..M}(任务 j 对应点 π(j) 与第 ν(j) 次巡检),节点 0=基地。决策:x_{j,j'}^{r} ∈{0,1}(机 r 是否在服务 j 后立刻飞往 j');时间变量 a_j^r(到达 j 的时刻,含服务后离开时刻 c_j^r = a_j^r + 5)。

目标(问题1.2):

$$\min\ T_{max} \quad \text{s.t.} \quad \forall r:\ \text{end}_r \le T_{max}$$

每台机路线:从 0 出发、按访问序列连接若干任务、返回 0;每个任务 j 恰被访问 1 次:
Σ_r Σ_{j'} x_{j',j}^r = 1, Σ_r Σ_{j'} x_{j,j'}^r = 1(流平衡,首尾接基地)。
时间递推:若 x_{j,j'}^r=1,则 c_{j'}^r ≥ c_j^r + τ·|p_{π(j)}−p_{π(j')}| + 5;返航 end_r ≥ c_j^r + τ·d_{π(j)}。

这是一个 min-max 车辆路径问题(min-max VRP),NP-hard;M 至 182,采用 **OR-Tools 路由求解器 + 引导式局部搜索(GLS)** 求高质量近似解(非精确最优,报告为"上界/构造解")。

### 4.2 数值实现要点(全部在 src/p1_case.py)

- 时间取**整数秒**:transit(i,j) = round(τ_s·|p_i−p_j|) + 300·[j>0],τ_s = 6.54545… s/u;时间维 cumul 精度 1 s。
- 目标:GlobalSpanCostCoefficient=100(分钟级 span 秒数 ×100 主导,弧代价=飞行秒数用于同 span 下的破平)。
- 初解 PATH_CHEAPEST_ARC;元启发 GLS;每解 3~6 个随机种子(CP-SAT random_seed),取 span 最小者。
- 求解时间:每算例 Nmin 搜索每次 ≤40 s、终解每次 ≤90 s(4 算例并行)。
- 工程修复:OR-Tools 9.15 + Py3.13 下 transit 回调内调用 SWIG 方法会抛 OverflowError,故在主线程预计算 transit 矩阵与 idx2node 字典,回调内仅纯 Python 查表(已由 `src/_smoke_915.py` 验证)。

### 4.3 独立校验(每次解输出后自动进行)

对每台机 r 重算:连续段飞行距离 Σ‖p_i−p_j‖、服务次数 ×5 min、总时长 = Σ飞行(按 55 km/h) + 5×n_tasks;与求解器 cumul 输出比对(容差 1 s/任务);校验:所有 M 个任务恰被覆盖一次、每机起止于基地、T_max ≤ 540 min(问题1)。任何不满足即宣告无效并重解。
