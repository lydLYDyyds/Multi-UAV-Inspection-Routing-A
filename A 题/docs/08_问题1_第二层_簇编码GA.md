# 问题1 第二层(1.2):簇编码遗传算法——Nmin 下的全局完成时间最小化

> 证据链:问题1.2 原文 → `src/ga_cluster.py`(簇编码 GA + ILS)→ `src/p1_makespan_ga.py`
> → `output/ga_p1_layer2_*.json` → `src/_verify_ga.py` 独立复核(全部 PASS)。
> 本层以第一层(ga_p1_*.json)的 Nmin 与最终划分为种子,在 N=Nmin 下继续最小化
> max_k T_k;产出问题一表2 的最终 N/Tmax/Tmin。

## 1. 任务契约

- **目标**:采用 Nmin 架无人机同时执行巡检任务,设计任务分配与路径规划,
  使总体完成时间 Tmax = max_k T_k 尽可能短(9 h 约束已由 Nmin 保证,此处继续压缩)。
- **输入**:第一层结果(每算例的 Nmin 与一个可行划分);附件1 坐标、等级展开任务集。
- **输出**:最终调度(逐机路线、逐任务到达/离开时刻)、表2 数值、与 OR-Tools 参考解的对比。

## 2. 簇编码 GA 设计(双层显式编码)

染色体 = N 条有序路线(簇)的列表,划分(任务→簇归属)与簇内访问顺序**同时显式编码**:

```
个体 = [ r1, r2, ..., rN ],  r_k = (t_{k1}, ..., t_{kLk})
约束:全部 M 个任务恰出现一次;适应度 = max_k T(r_k),副目标总时长破平
```

### 2.1 簇间算子(划分层,本层重点)

| 算子 | 做法 | 说明 |
|---|---|---|
| 交叉:路线继承 | 继承父代1的最长路线 + 父代2中不冲突路线;冲突任务剔除后按最便宜插入修复,空簇先各补一个距基地最近的任务 | 好簇整体遗传,保持 N 个非空簇 |
| 变异:跨簇交换 | 两簇各取一任务互换(按 ΔT 评估,仅接受 makespan 不上升) | 用户指定的"簇间交换" |
| 变异:跨簇搬移 | 最长簇一个任务搬到另一簇最佳位置(仅接受 makespan 不上升) | 压缩最长簇 |
| 变异:簇级重组 | 最小簇并入其他簇 + 最大簇按最远两点种子拆二 | 保持 N,粗粒度重划分 |

### 2.2 簇内算子(布线层)

- 变异:簇内两点交换、区段反转(无条件接受,提供多样性);
- 引擎:**最近邻贪心**构造(nn_order)+ **2-opt / Or-opt** 确定收敛(two_opt_all、intra_or_opt);
- 精修:**簇内模拟退火**(intra_sa:交换/反转移动 + Metropolis 准则,初温 10 min 线性退火,仅接受改善)。

### 2.3 拉马克式局部搜索 + ILS 末段

- 对最优解复用 `ga_minmax.local_search`(机内 2-opt/Or-opt,跨簇 relocate/exchange/块搬迁/2-opt*),
  只接受 makespan 严格下降;
- **ILS 末段**(`ils`,300 次迭代):强制随机跨簇扰动(交换/搬移 k=3 次,不回退检查)+ 局部搜索收敛,
  突破"所有种子收敛到同一深局部最优"的平台(典型:Case3 第一层 8.829 h 卡住)。

### 2.4 参数与可复现性

pop 40、≤500 代、patience 200、灾难式重启(每 100 代无改进保留 15% 重随机化)、4 种子、
ILS 300 迭代;种子 = ci×7000+s(ci=1..4);全部写入 JSON。单算例墙钟 26~154 s(4 核并行)。

## 3. 必须如实记录的关键工程事件

分层求解期间,独立复核先后发现**两处**局部搜索时间增量缺陷,均已 fuzz 定位、修复、
回归并把两层/ACO 结果按修复后代码重跑:

1. **2-opt\* 前缀和 off-by-one**(`_fuzz_ls.py` 定位):前缀和与"切片内部距离"语义差一条
   边界边,导致个别解的 makespan 报告值与真实值不符;
2. **Or-opt 块内距离公式**(`_fuzz_ils.py` 定位):机内/跨机块搬迁的块内距离应为
   pref[p+b]−pref[p+1](原为 −pref[p],p≥1 时多含一条边界边),被接受的移动会使
   记录时间低于真实时间,曾在打磨阶段被独立校验拦截。

结论:Nmin 结论全程不变(4/2/4/4,最终调度均经独立重算校验);
修复后全部算例按新代码重跑,结果只增不减(如 Case4 第一层 8.393→8.015 h)。

## 5. 诚实性声明

1. 所有数值均为启发式上界(无全局最优证明);"反超 OR-Tools"仅指该参考运行的值,
   不代表全局最优;
2. 簇内模拟退火与 ILS 的随机性由固定种子控制,可复现;
3. 同一物理点多次巡检可由同一机连续完成(假设 A2)沿用;
4. 本层输出的调度明细(逐任务到达/离开时刻)见 `output/ga_p1_layer2_*.json`,
   可直接转写 result1.xlsx。
