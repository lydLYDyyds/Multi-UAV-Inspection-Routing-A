## 3. 结论(论文表述口径)

1. **Nmin**:Case2 的 Nmin=2 由下界+构造严格证明;Case1/3/4 的 Nmin=4 由构造确立,N=3 不可行性以求解证据支撑(最优尝试 9.12/10.56/10.17h),证明缺口如实披露。
2. **均衡**:问题2 在改善 makespan 的同时,将 δ 显著压缩——Case1 0.171→0.077 h(-55%)、Case4 0.050→0.030 h(且 Tmax 8.020→7.804 h,双目标同优);Case2 的 δ 达 0.002 h(6 s);Case3 的问题1 解已近 Pareto。二分搜索(容差 2 min)相对 30 min 粗网格在 4/4 算例严格占优。
3. **禁飞区**:统一时空硬约束模型(F_ij 禁止出发区间 + τ~=min{直飞,等待,绕行} + 三态验证)在全部算例实现零违例;ALNS 全局优化在其上进一步把 Case2/3/4 的均衡度压至 0.038/0.103/0.039 h。禁飞区对 Case2 影响最大(+3.84 h,基地核心区被 4 区覆盖),说明禁飞区的位置/覆盖比数量更关键。
4. **鲁棒性**:速度 55±9%、服务 5±1 min、半径 +20%、任务 ±5% 下结论方向稳定;S5 显示"连续巡检"假设对 Case3 有实质影响,建议运营上优先保障该算例场景的间隔巡检能力。

## 4. 局限与建议(不回避)

- 欧氏直线飞行假设;实际低空需考虑建筑/地形(问题3 仅圆形禁飞区)。
- GLS 给出高质量上界而非全局最优;makespan 与理论下界间存在未闭合间隙。
- 问题3 采用"区内原地等待至解除"语义(等效区外盘旋,延迟相同);多次巡检连续完成的假设见 A2。
- 建议:①按禁飞区时空分布动态重规划(本文修复式算法可直接嵌入);②对 Case3 类场景配备第 5 架备份机;③关键设施(等级 I)可错峰安排以规避禁飞时段。
