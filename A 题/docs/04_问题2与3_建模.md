## 1. 问题2:双目标(时长最短 + 负载均衡)

### 1.1 数学表述

在问题1 的基础上,每台机 r 的工作时长 T_r(起飞到返航)。两个目标:

- 主目标:makespan T_max = max_r T_r 尽量短;
- 次目标:均衡度 δ = T_max − T_min(T_min = min_r T_r)尽量小。

采用**分层(词典序)目标规划**:第一层解出 T* = 问题1 最优 makespan;第二层在 T_max ≤ T*·(1+ε) 内最小化 δ。ε 取 0、1%、2% 三层,报告 Pareto 剖面;论文正文采用 ε=0 层(不牺牲 makespan 的最大均衡),并给出 ε>0 的权衡。

### 1.2 算法(ε-约束 + 下界 L 二分搜索)

对第二层引入各机工作时长下界 L:约束 T_r ≥ L(∀r),最小化 T_max。当 L 增大,任务被强制分摊,δ = T_max − min T_r 下降;L 超过可行值后 T_max 上升。可行域单调:**P(L) 可行 ⇒ 所有更小的 L 可行**,故可用二分搜索:

1. 对每个 ε 层在 L ∈ [0, T*·(1+ε)] 上二分(容差 2 min,≤⌈log₂(T*/2min)⌉≈8 次 oracle 调用);每个 L 用 OR-Tools(GLS,2 随机种子,30 s)求 min T_max(与问题1 完全同机制,见 §1.3);
2. 探针结果跨层缓存共享(不同 ε 层只差 span 上限检查,同一 L 不重解);二分收敛后在边界上方再探 1~2 步,修复启发式 oracle 的单步噪声;
3. 层内选择:span ≤ T*·(1+ε) 的全部候选(含问题1 原解)按 (T_max, δ) 词典序取最优;
4. 独立性校验同问题1。

> 旧版 30 min 粗网格(`src/p2_case.py`)保留为对照实验;最终论文采用二分版(`src/p2_bin.py`),两者结果一致则互相印证。二分法完整原理推导、逐步计算实录与解质量证书见 `docs/09_问题2_二分法原理与计算过程.md`。

下界约束在 OR-Tools 中通过 `CumulVar(End_v) ≥ 60L` 直接加入约束求解器。

### 1.3 算法形式化表述(论文 4.2 节采用;OR-Tools 机制的正式写法)

**子问题 P(L)(OR-Tools 实际求解的精确形式)**

输入:任务集 J={1,…,M}(任务 j 坐标 p_j、单次服务时长 s=300 s),基地 0,机数 N,工作时长下界 L。决策:0-1 路径变量 x^r_{j,j'}、时间变量 c^r_j(机 r 完成服务 j 的时刻)。

min T_max,约束:

(i) 每台机自 0 出发并返回 0,出入度流平衡;
(ii) 任务恰被服务一次:Σ_r Σ_{j'} x^r_{j',j} = 1, ∀j;
(iii) 时间递推:x^r_{j,j'}=1 ⇒ c^r_{j'} ≥ c^r_j + τ·|p_j−p_{j'}| + s;
(iv) 返航:end_r ≥ c^r_j + τ·|p_j|(j 为该机末任务);
(v) 均衡下界:end_r ≥ L, ∀r;(vi) end_r ≤ T_max。

**OR-Tools 的机制映射(把上式逐条交给求解器的正式说法)**

- 图模型:`RoutingIndexManager(M+1 节点, N 车, depot=0)`;节点间代价 c(j,j′)=round(τ_s·|p_j−p_{j′}|)+s·1[j′>0](整数秒制);
- 时间维:'Time' Dimension:transit 回调=c、松弛量 slack=0、车辆容量 20×HORIZON;累计变量 CumulVar 即 c^r_j 与 end_r;(v) 由 `solver().Add(tdim.CumulVar(End_v) ≥ L)` 实现,(vi) 由 span 机制实现;
- 目标:全局跨度系数 β=100 把求解器目标设为 f = β·span + Σ_arc c(秒制),数值上 span 主导、弧长和为次级破平项——即词典序 (span, arc_sum) 的加权近似;
- 初解:PATH_CHEAPEST_ARC(贪心最近插入);元启发:GLS(Guided Local Search):以弧为特征、局部最优处对高代价特征累加罚因子 p_e,增广目标 f′=f+λ·Σ_e p_e·1[e∈解],λ 自适应;终止条件:时间上限 t;
- 多种子:CP-SAT random_seed ∈ {1,2},各解一次取 span 小者。

**算法1:LEX-BALANCE(二分最大可行下界,论文伪代码)**

```
输入:J, N, T*(问题1 最优值), ε 层 {0,1%,2%}, 容差 Δ
输出:Pareto 剖面 {(ε_k, T_k, δ_k, 调度_k)}
for each ε in {0, 0.01, 0.02}:
    lo←0; hi←T*; L*←0; best←问题1 调度
    while hi−lo > Δ:                    # 二分;可行域单调收缩
        L←(lo+hi)/2
        (可行?, T̂, 调度̂)←ORACLE(L)      # 解 P(L),机制见上
        if 可行? 且 T̂ ≤ T*(1+ε):
            L*←L; best←(T̂, 调度̂); lo←L
        else:
            hi←L
    T_k←best.T̂; δ_k←T_k − min_r end_r(best)
return {(ε_k, T_k, δ_k, 调度_k)}
```

**正确性与复杂性(诚实表述)**

- 引理(单调性):若 P(L′) 可行,则 ∀L≤L′,P(L) 可行(约束集单调收缩),故可行 L 集为区间 [0, L*(ε)],二分成立的前提严格成立;
- 命题(精确 oracle 下):若 ORACLE 精确,算法1 经 O(⌈log₂(T*/Δ)⌉) 次调用返回 L*(ε) 的 Δ-近似,所得 δ_k 为该 ε 层内最优;
- 诚实声明:实际 ORACLE 是 GLS 启发式,"未找到解"≠"不可行",故所得 L* 是**启发式最大下界**(对真值的下界,一个可复现的证书);论文表述为"在搜索网格与时限内可达的最大均衡",并用 δ ≥ (N·T_max−S)/(N−1)(S=Σ_r T_r)作间隙证据;
- 复杂度:每层 ≤ ⌈log₂(9×60/Δ)⌉ ≈ 10 次 oracle 调用,每次 ≤ 2 种子 × 30 s;M≤182、N≤4,单次调用内 GLS 邻域为 O(M²) 规模弧交换。

**OR-Tools 的正式引用**:软件引用 "Google OR-Tools, v9.x Routing Library";或引 Perron L, Furnon V, *OR-Tools* 文档(CP-SAT/Routing)。

## 2. 问题3:临时禁飞区

### 2.1 约束形式化

附件2 给出禁飞区 z=(c_z, r_z, t0_z, t1_z)(圆、生效时段;时刻自 8:00 计)。约定(依据与理由见 01 台账 A-假设):

- 无人机轨迹为折线;某飞行段在**实际穿越时段** [t_dep, t_arr] 内,若折线与"当时生效"的禁飞圆**内部**相交,即为违例;相切/沿边界飞行允许(开圆约定)。
- 巡检服务:若点 p 位于圆 z 内部,其 5 min 服务时段与 z 的生效时段重叠即为违例;可空中等待至解除后服务(题目未禁止等待,无人机低速悬停能力为前提,记入假设)。
- **Case4 Z8 的 17:00–17:00 零长度窗口**:按"瞬时生效"处理(开区间重叠判定下永不生效);敏感性分析补充"17:00 起持续生效"的对照。

### 2.2 算法:航段级硬约束模型(最终采用)+ 带时间窗再优化

**核心(与《动态禁飞区域下的航段级硬约束模型》§1-§20 逐节对应;实现 `src/nofly.py`)**

1. **解析判交(§3-§5)**:航段参数化 p(λ)=A+λ(B−A)、t=t_dep+λτ;与禁飞圆 |p−c|²=R² 联立得 aλ²+bλ+c=0,取 [λ₁,λ₂]∩[0,1](开圆约定:相切/端点接触不算)→ 穿越时段 [t₁,t₂],与生效窗口重叠 ⟺ 冲突。
2. **禁止出发区间 F_ij(§6-§8,预计算)**:冲突 ⟺ s ∈ F_ijq=(a−λ_out·τ, b−λ_in·τ);并并入两个点级项(§13):到达服务项(v 在图内,服务+离场须在激活前完成: s ∉ (a−5−t_exit−ε−τ, b−τ))与离场时限项(u 在图内: s ∉ (a−t_exit−ε, b));F_ij = 区间并集,全部 (i,j) 预计算一次。
3. **动态航段代价 τ̃_ij(s) = min{直飞, 等待, 绕行}(§9-§11)**:
   - 直飞:s ∉ F_ij;
   - 等待:s′ = inf{u≥s : u∉F_ij}(+0.03 min 裕度),τ_wait=(s′−s)+τ;
   - **圆外悬停(§14)**:等待期间若 u 位于生效区内,先飞至圆外悬停点 w(沿航向或最近边界,外推至全部包含区外)再等——等待位置本身也是硬约束;
   - 绕行(§10):双切线 8 候选,弧离散半径 R=r/cos(θ/2)+0.05 向外偏移;绕行折线按实际路径解析验证(含实际到达服务约束)。
4. **调度时间递推(§12)**:A_{l+1}=D_l+τ̃(D_l),D_{l+1}=A_{l+1}+5。
5. **三类状态独立验证(§13/§14/§20 第五步)**:飞行段(按等待位置分段的真实时段)、服务时段、等待时段(位置×窗口)全部解析核对,违例=0。

**Pass A(修复式)**:以问题2 调度为初解逐段按 τ̃ 重建;**Pass B(≤2 轮)**:任务到达时间窗(点级)的 OR-Tools 再优化(带窗 L*±1h + 自由 0..span+1 网格),tex 修复 + 三态校验,(T_max, δ) 严格更优则接受。

**阶段 VI:ALNS 全局优化(`src/alns3.py`,伪代码《Dynamic No-Fly Constrained Multi-UAV Routing》阶段 VI)**:以 Pass A/B 结果为初解,300 迭代 ×(破坏-修复 + 局部搜索 + SA 接受):

- 破坏:①最长路线任务 ②禁飞敏感航段(等待/绕行)附近任务 ③随机 ④空间相近簇,每次删 4~8 个;
- 修复:对每个被删任务枚举全部"无人机 × 插入位置",用 `nofly.build_route` 计算真实 ΔTmax(含 τ̃ 与三态硬约束),取词典序最优合法插入,不可行拒绝;
- 局部搜索:relocate / swap / 2-opt(段反转) / cross-exchange(跨机换尾),每个算子随机尝试 60 次首改进;
- 接受:(Tmax, δ) 词典序改进必收,否则按 SA 概率 exp(−ΔTmax·60/T) 收(T0=0.05 h,冷却 0.98),连续 80 次无改进终止;
- 最终解经三态独立验证,违例=0 才输出。实测:Case2 11.921/0.117→10.969/0.038,Case3 δ 0.550→0.103,Case4 δ 0.300→0.039(Case1 持平)。

> 工程注:①旧版 `src/p3_case.py` 圆弧离散点 (sin,cos) 坐标反位 → 绕行弦穿入圆内、绕行永远被自身校验拒绝;tex 版修复并向外偏移。②旧校验器"整段飞行窗口×禁飞窗口"粗判定会误报合法航段;`src/p3_export.py` 已升级为解析判交三态校验(独立实现)。③F 表按直飞几何预计算,hop/绕行路径的到达与穿越时刻在候选构造时以实际路径重新校验并延长悬停,闭环保证。
