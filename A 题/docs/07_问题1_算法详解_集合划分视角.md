# 问题一第一部分算法详解:最小簇数集合划分视角

> 适用范围:问题一第一部分——在 9 小时(540 min)内完成全部巡检任务,求理论最小无人机数 Nmin。
> 本文件按"集合划分"视角系统讲解候选算法在本问题中的具体用法、伪代码、复杂度与利弊;
> 实现状态(已实现 / 未实现 / 可选)如实标注。模型公式与"问题一第一部分.pdf"一致,
> 全部时间以分钟计:τ = 6/55 min/u 为飞行单位坐标距离耗时,单次巡检服务 s = 5 min。

---

## 1 问题重述与数学模型(集合划分视角)

### 1.1 任务展开:高等级点拆成多个"编码不同、坐标相同"的点

附件1 给出 n 个巡检点,点 i 的巡检等级 I/II/III 对应巡检次数 k_i = 3/2/1。
把每个点 i 展开为 k_i 个**任务**(虚拟点):


J = {(i,\nu): i=1..n, \nu=1..k_i},   M = |J| = \sum_i k_i


同一物理点 i 的 k_i 个任务坐标相同、编码(任务 id)不同。4 个算例的 M = 72 / 139 / 140 / 182。
这正对应问题原文"从不同方向、不同高度或**不同时间**获取信息"的建模自由:
同一点的多次巡检既可分散给多台机,也可由同一台机一次到达连续完成(假设 A2,见 docs/03)。

### 1.2 决策变量与目标

- **决策**:把任务集 J 划分为 N 个非空子集(簇) C_1,…,C_N,⊔_r C_r = J;
  每个簇 C_r 由第 r 台无人机服务。
- **簇的工作时间**(该机从基地出发、访问簇内全部任务、返回基地,簇内顺序取最短者):


T(C) = τ· L^*(C) + 5·|C|,
   L^*(C) = TSP({0}∪ C) 的最短回路长度


- **约束**:\max_r T(C_r) ≤ 540(9 h);所有机 8:00 同时起飞,完成各自任务后返回。
- **目标**:


min N   s.t. 存在满足上式的划分


即"**最长时间 ≤ 9 h 前提下划分集合数最小**"——与 PDF 中 min N s.t. max T_k ≤ 9 完全一致。

### 1.3 两个结构性事实(决定算法框架)

**事实 1(单调性)**:若 N 台机可行,则 N+1 台机可行。
证:取可行划分中任意一个簇 C,删去 C 的回路中一些点并做三角不等式"抄近道",
可得 C 的一个子簇 C′ 满足 L^*(C') ≤ L^*(C) 且 5|C'| < 5|C|,故 T(C′) < T(C);
把 C 拆成 C′ 与 C∖C′,两部分时限都不超过 T(C) ≤ 540。∎
⇒ **可行性关于 N 单调**,因此可以"从下界起递增试探"或"二分搜索" N。

**事实 2(子问题 NP-hard)**:即使 N 给定,判定"是否存在时限 540 的 N 划分"也含装箱
(每个任务的时间重量)与 TSP(簇内路线)两个 NP-hard 成分;故大规模下无法多项式精确求解,
必须组合"下界 + 启发式构造 + 元启发式"。

**总框架**(所有算法按此组合):

```
N_LB = 下界(N < N_LB 不可能)
对 N = N_LB, N_LB+1, ...:
    用(近似)算法求 min-makespan 划分,得最优时限 T*_N(近似)
    若 T*_N ≤ 540: Nmin = N,停止
    否则记录 T*_N 作为 N 不可行的经验证据
```

## 2 算法一:理论下界(先验排除过小的 N)

下界的作用:**严格证明某些 N 不可能**,从而给出 Nmin 的证明起点,并压缩搜索范围。

### 2.1 总工作量下界

任意划分中,全部机总工时 = 服务总时间 5M + 飞行总时间 T_fly。
若 N 台机均在 540 内完成,则总工时 ≤ 540N,故


N  可行 ⇒ 5M + LB(T_fly) ≤ 540 N
  ⇒  
N ≥ ⌈ \frac{5M + LB(T_fly)}{540} ⌉


### 2.2 飞行总时间的几何有效下界 LB1–LB5

记 d_i 为任务(点)到基地的欧氏距离,d_(1)≥ d_(2)≥… 为降序,每式均为任意可行调度的必要条件:

| 下界 | 表达式(飞行总时间,min) | 依据 |
|---|---|---|
| LB1 | 2τ d_(1) | 服务最远点的机至少往返基地一次 |
| LB2 | (2τ)/(n)\sum_i d_i | 每机路线长 ≥ 2×其服务点距离的均值 |
| LB3 | τ(d_a+d_b+|p_a-p_b|) | 最远两点无论同机/异机,均有此界(三角不等式) |
| LB4 | τ\min_a<b\inTop(N+1)(d_a+d_b+|p_a-p_b|) | N 台机、最远 N+1 个点必两点同机(鸽笼) |
| LB5 | 2τ(d_(1)+最小的 N-1 个 d) | N 台机均非空时,各机长 ≥ 2×其最远点距离 |

取 LB(N) = 5M + τmax(LB1..LB5),则


N_LB = min{N : LB(N) ≤ 540N}


**用法**:N < N_LB 严格不可行;Nmin ∈ [N_LB, +∞)。4 算例实测 N_LB = 2/2/2/3(代码 `src/p1_lb.py`、`p1_nmin_ga.lower_bound_N`)。

**可选的更强界**:Held-Karp 1-tree 下界(含基地的生成树 + 一条边),比上述界更紧,
适合在论文中作补充;本方案未实现,不影响结论。

**诚实声明**:LB1–LB5 只用几何端点信息,未计入"必须覆盖全部点"的路径总长,对 N≥2 偏松;
因此下界只排除"过小 N",Nmin 的最终确认靠构造可行划分(见下)。

## 3 算法二:贪心顺序装箱(快速构造上界)

### 3.1 思想

把任务按某种优先级排序,依次"装箱":当前簇装不下(时限将超 540)就封箱、开新簇。
这是装箱问题 First-Fit-Decreasing 思想的类比,输出**可行的簇数上界 N_ub**
(以及一个合法调度),速度快、可复现,用作基准与元启发式的初解。

### 3.2 伪代码

```
输入: 任务集 J, 距离矩阵 dist, 时限 H=540
排序: 按到基地距离降序(远点优先装,降低封箱后剩余任务的难度)
簇列表 C = [];  当前簇 cur = 空集, cur_time = 0
for 任务 j in 排序后的 J:
    在 cur 中枚举插入位置,取使路线增量最小的位置 pos
    t_new = τ·(插入后路线长) + 5·(|cur|+1)
    if cur 非空 且 t_new > H:          # 装不下 → 封箱
        C.append(cur);  cur = 空集;  重新为 j 计算 t_new(单独成簇)
    cur.insert(j, pos);  cur_time = t_new
C.append(cur)                           # 最后一箱
输出: N_ub = len(C), 划分 {C_r}
```

### 3.3 实现细节

- **插入代价**:簇内路线用有序列表维护,插入位置 pos 的路线增量 =
  τ(dist(a,j)+dist(j,b)-dist(a,b)) + 5,a、b 为插入位置前后任务(首尾处 a 或 b 为基地)。每任务 O(|cur|),单算例总代价 O(M²),毫秒级。
- **封箱后精修**:每封一个簇,对簇内路线跑一次 2-opt + 机内 Or-opt(见第 6 节算子),进一步压缩其时间——只花几毫秒,常使后续任务更容易装入。
- **排序变体**:远点优先(推荐)、按极角扫掠、按坐标 x 排序等,可多跑几种取 N 最小者。

### 3.4 性质与用法

- 输出是**构造解**,因此 N_ub 是 Nmin 的可靠上界;但装箱顺序贪心,通常比最优多 1~3 台机。
- 用法:① 论文中作基线算法;② 给出 Nmin 搜索区间的右端 [N_LB, N_ub];
  ③ 其划分可直接作为 GA(第 5、6 节)初始种群的种子个体。
- 状态:未实现(描述性算法),如需实现约 40 行代码。

## 4 算法三:先分簇后布线(cluster-first, route-second)+ 对簇数搜索

### 4.1 思想

把"划分 + 布线"拆成两步:先用**聚类**把 M 个任务分成 k 组,再对每组解 TSP(2-opt/LKH);
检查 max 簇时间 ≤ 540。对 k 做递增或二分搜索,首次可行即 Nmin 的上界。

### 4.2 分簇:带权 K-means++(或 K-medoids)

- 样本 = M 个任务坐标(同坐标副本照常作为独立样本);
- 初始化用 **K-means++**(最远点概率采样),避免普通 K-means 的坏初值;
- 迭代:任务就近归簇 → 更新簇中心(均值或取簇内点作 medoid)→ 至收敛。
- **注意时限成分**:T(C)=τ L^*(C)+5|C| 中 5|C| 与簇大小成正比,K-means 只平衡空间距离,
  未考虑簇大小;因此聚类后必须做"簇间再平衡"(见 4.4)。

### 4.3 布线:每簇 TSP

每簇(含基地)用最近邻 + 2-opt(或调用 LKH 子程序)求回路,得 T(C_r),取 max 与 540 比较。
由于单调性(事实 1),k 的可行性单调,可直接二分;但聚类结果有随机性,每个 k 建议跑 3~5 次。

### 4.4 簇间再平衡(关键一步)

对超时限的簇 C_long,把其中的任务逐个 reloc/cluster 到其他簇(选插入代价最小者),
再 2-opt 两端路线;重复至 max ≤ 540 或无可动。这一步等价于第 6 节局部搜索的跨簇算子,
是把"先分簇后布线"从概念算法变成可用算法的必要补充。

### 4.5 伪代码

```
for k = N_LB .. M(或二分):
    for restarts in 1..5:
        簇 = K-means++(任务坐标, k)
        for r in 1..k: 路线[r] = 最近邻+2-opt(簇[r]); 时间[r] = τ·len+5·|簇[r]|
        簇间再平衡(relocate, 直至 max≤540 或不动)
        if max(时间) ≤ 540: return 可行, Nmin ≤ k
```

### 4.6 优缺点

- 优点:直观、步骤清晰、好写进论文;K-means 部分可给出"空间分区"的物理解释。
- 缺点:① 聚类不考虑时限,可能出现某簇"天生超时";② 对 k 的每次判定都要多次重启,
  总耗时高于贪心装箱;③ 只能给出上界/经验不可行证据,无最优性保证。
- 状态:未实现,推荐作为**对照算法**而非主算法。

## 5 算法四:分组编码遗传算法(划分视角最直接的 GA)

### 5.1 编码与译码

- **编码(分配向量)**:染色体 a ∈ {1,…,N}^M,基因 a_j = 任务 j 所属簇编号。
  直接对应"划分"本身,是本问题语义最自然的 GA 形式。
- **译码**:对每个簇 C_r = {j : a_j = r}(非空)解 TSP——最近邻 + 2-opt——得 T(C_r)。
- **适应度**:


f(a) = \max_r T(C_r) + P·max(0, \max_r T(C_r)-540) + P'· \#{空簇}


  罚项 P 迫使可行;空簇罚项防止"减机"作弊。取 P = 540、P′ = 540 即可,罚参数不敏感。

### 5.2 遗传算子

| 算子 | 做法 | 说明 |
|---|---|---|
| 选择 | 三元锦标赛 | 按 f 越小越好 |
| 交叉 | 均匀交叉:每个基因位随机取父代一方的簇号;或"簇交换交叉":把父代 A 的整个簇 r 复制给子代 | 后者保留簇的完整语义,收敛更稳 |
| 变异 | ① 随机把一任务改派到其他簇;② 随机合并两簇;③ 随机拆开一个簇 | ②③ 提供"簇数微调"能力 |
| 修复 | 出现空簇时,从最大簇搬一半任务过去 | 保持恰好 N 个非空簇 |

### 5.3 求解 Nmin 的用法

固定 N 跑 GA(多种子),best 适应度中 max T ≤ 540 即 N 可行;自 N_LB 递增,首次可行即 Nmin。
**不推荐**直接"最小化簇数"(把 N 放染色体):空簇/罚参数耦合会破坏搜索稳定性。

### 5.4 伪代码

```
for N = N_LB .. :
    for seed in 1..6:
        种群 = 随机分配向量 + 贪心装箱结果(作种子个体)
        for gen in 1..G:
            锦标赛选择 → 交叉 → 变异 → 修复空簇
            译码(每簇 NN+2-opt) → 适应度
            精英保留;最优个体再做跨簇 relocate/exchange 局部搜索
        if best.maxT ≤ 540: Nmin = N,停止
    记录 N 的 best.maxT(不可行证据)
```

### 5.5 与排列编码 GA(第 6 节)对比

| 维度 | 分组编码 | 排列编码(已实现) |
|---|---|---|
| 表达划分 | 直接,概念最贴题 | 间接(排列 + 切点) |
| 译码成本 | 每代每簇都要解 TSP | 分割 DP 一次到位,O(MN log M) |
| 簇结构继承 | 交叉可整簇搬移,好 | OX 只保序,簇信息靠分割恢复 |
| 局部搜索耦合 | 需另行跨簇算子 | 与分割/解码天然配套 |
| 工程成熟度 | 需自行调参 | 已实现并跑通 4 算例 |

结论:分组编码 GA 是**最有"划分"说服力的对照算法**,适合论文写"两种编码互为验证";
但工程上排列编码更省事、更稳。

## 6 算法五:排列编码遗传算法(巨型路线 + 最优分割)——已实现,主算法

### 6.1 编码与适应度(把"划分"编码为"排列 + 切点")

- **染色体**:M 个任务的排列(巨型路线);
- **适应度**:把排列按顺序切成 N 个非空连续段(每段 = 一个簇),切法使最长段最小,
  由**精确动态规划**给出(对该排列而言是精确的最优划分):


g_k[i] = \min_j=k..i max(g_k-1[j-1], c[j,i]),
  
c[j,i] = τ(d_j + \textstyle\sum_t=j^i-1dist(t,t{+}1) + d_i) + 5(i-j+1)


  利用 c[j,i]=u[j]+v[i]+5 的可分结构与两个堆把复杂度压到 **O(MN log M)**
  (与 O(M²N) 暴力 DP 随机对照 300 组零偏差,`src/_test_ga.py`)。

### 6.2 遗传算子

- 初始化:最近邻巨路 + 按基地扫掠角排序巨路 + 随机排列(前两者保证初代即有可用划分);
- 选择:三元锦标赛;交叉:OX(概率 0.9);变异:两点交换 / 区段反转 / 移位;
- 精英 2;连续 120 代无改进时保留最优 15% 重随机化其余(灾难式重启);
  连续 250 代无改进提前终止;
- 可行快路径:任何时刻发现 ≤ 540 的划分立即停机。

### 6.3 局部搜索 = 簇边界修正(与第 4.4 节同一套思想)

对最优解译码出的簇执行,仅接受 makespan 严格下降的移动:

| 算子 | 作用(划分视角) |
|---|---|
| 机内 2-opt / Or-opt | 簇内布线修正,不改变划分 |
| 跨簇 relocate / exchange | 把最长簇的一个任务移给/换给其他簇 —— 修正划分 |
| 跨簇块搬迁 Or-opt | 连续 2~3 个任务整体换簇 —— 粗粒度修正划分 |
| 跨簇 2-opt\* | 切断两簇回路并交叉重连 —— 同时修正划分与布线 |

## 7 算法六:精确方法(集合划分 / 分支定价,可选)

若要在小算例上**证明** Nmin 的最优性(而非经验证据),可用的精确框架:

### 7.1 集合划分配方(Set Partitioning)

列 = 一个可行簇(路线):C_L \subset J 且 T(C_L)≤ 540(簇内顺序取该簇的最短 TSP)。


min \sum_L y_L
 s.t. 
\sum_L: j∈ C_L y_L = 1 ∀ j,   y_L∈{0,1}


最优目标值 = 精确 Nmin。列数指数级,需列生成:

### 7.2 定价子问题(列生成)

主问题(LP 松弛,集合覆盖)的对偶变量 \pi_j 下,新列需满足
\sum_j∈ C\pi_j > 1,即求**带资源约束的基本最短路(ESPPRC)**:
从基地出发访问若干任务再回基地,累计时间 ≤ 540,收益 = Σ\pi_j 最大。
用标签算法(label-setting DP)求解;对偶间隙大时嵌入**分支定价**。

### 7.3 MILP 备选(小算例)

固定 N 的可行性判定可用 MTZ 消子环的混合整数规划(Gurobi/CPLEX),或 min-max 目标直接求。
Case1(M=72)规模勉强可限时求解;M=140+ 基本超时,只能取界。

### 7.4 适用性判断

- 优点:能给出**可证明的** Nmin(严格性最强);
- 缺点:实现工作量(ESPPRC 标签算法、分支规则)远大于元启发式,竞赛时间预算内性价比低;
- 建议:不作为主算法;若论文需要"Case2 之外严格性"的讨论,可用 MILP 在 Case1 上限时求下界作对照。
- 状态:未实现(可选扩展)。
