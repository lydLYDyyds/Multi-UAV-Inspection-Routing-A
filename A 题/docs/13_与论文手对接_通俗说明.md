# A 题求解总说明(与论文写作者对接版)

> 本文以"简单数学原理"为主线,把三个问题的建模思路、求解方法与结果串成一条完整
> 逻辑链,供论文写作直接参考。所有数值来自最终结果并经独立校验,可直接引用。

## 1 问题概述

设基地为坐标原点,无人机巡航速度 v=55 km/h(忽略起降),单次巡检服务时间 s=5 min,
8:00 为时间原点,各机完成本机任务后返航。巡检点按等级 I/II/III 分别需要巡检
3/2/1 次,记全部巡检次数为 M(同一点多次巡检视为多个重合任务)。第 r 架无人机的
工作时长记为 T_r,定义

$$T_{max}=\max_r T_r,\qquad T_{min}=\min_r T_r,\qquad \delta=T_{max}-T_{min}.$$

三个问题依次为:

- **问题1**:9 h 内完成全部任务所需的最小无人机数 Nmin;并给出 Nmin 架下使 T_max
  最小的任务分配与路径;
- **问题2**:在问题1 基础上,先使 T_max 尽量短,再使 δ 尽量小;
- **问题3**:加入动态圆形禁飞区(空间圆 + 生效时间窗),飞行、服务与等待三类状态
  均不得在禁飞生效期间处于禁飞区域内,目标与问题2 相同。

---

## 2 问题1:最小无人机数与最短完成时间

### 2.1 最小无人机数的证明结构:下界 + 构造

任意调度中,总工时 = 服务总时长 + 飞行总时长。服务总时长恒为 5M(min);飞行时间
存在与分组无关的下界,例如:服务最远点 p* 的无人机往返飞行不少于 2‖p*‖ 对应的时间;
N 台无人机各至少服务一个点时,其飞行时间之和不小于"1 个最远往返 + N−1 个最近往返"。
由此得到

$$N_{\min}\ge N_{LB}:=\min\{N: 5M+\tau\cdot LB_{fly}(N)\le 540N\},$$

其中 τ 为单位坐标的飞行时间。下界说明"少于 N_LB 架数学上不可能";再用求解器构造
N 架的完整可行调度,说明"这么多架确实够"。两面包夹确定 Nmin。

### 2.2 最短完成时间的求解

将"最晚返航时刻"作为目标,用 OR-Tools 求解(贪心构造初解 + 引导式局部搜索,多种子
取优)。四个算例结果为 Nmin = 4/2/4/4,最短完成时间见第 5 节表2。

> 口径说明:Case2 的 Nmin=2 由"下界 + 构造"严格得证;Case1/3/4 的 Nmin=4 由构造
> 得证,N=3 的不可行性以"多次长时限求解均超过 9 h"作为经验证据,文中如实表述。

## 3 问题2:先最短、后均衡(词典序双目标)

### 3.1 建模:引入工作时长下界 L

对每台无人机施加约束 T_r ≥ L。L 的作用是强制分摊任务:

- L 增大 → 各机时长趋近 → δ 减小;
- L 超过可行极限 → T_max 被迫增大。

因此第二目标可转化为:在 T_max ≤ T*·(1+ε) 的约束下,求最大的可行 L。可行域具有
**单调性**:若"所有机 ≥ L 且 T_max ≤ 上限"可行,则对任意更小的 L 也必然可行
(同一调度即证)。于是可行 L 的集合是区间 [0, L*]。

### 3.2 二分搜索

由单调性,对 L 做二分搜索,每层 ε 只需约 ⌈log₂(T*/2min)⌉ ≈ 8 次求解即可把搜索
区间从约 8 h 压缩到 2 min。每个探针 L 解如下子问题:

$$\min\ T_{max}\quad s.t.\quad T_r\ge L\ (\forall r).$$

取 ε = 0/1%/2% 三层,得到"以多少完成时间换取多少均衡"的权衡剖面。

### 3.3 均衡度的下界证书

对任意调度,设总工时 S = Σ_r T_r,则

$$\delta \ge \frac{N\cdot T_{max}-S}{N-1}.$$

证明:除最长机外 N−1 台机的时长均 ≥ T_min,故 S ≥ T_max + (N−1)·T_min,移项即得。
该证书给出"给定总工时下均衡的极限",Case2 的解恰好达到此下界。

## 4 问题3:动态禁飞区下的统一时空硬约束模型

### 4.1 时空禁飞域与世界线

禁飞区 q 由圆心 c_q、半径 R_q 与生效时间窗 (a_q, b_q) 组成,定义时空禁飞域

$$F_q=\{(p,t):\|p-c_q\|<R_q,\ a_q<t<b_q\}.$$

无人机 k 的时空轨迹(世界线)为 Γ_k = {(p_k(t), t)},则全部禁飞约束统一写为

$$\Gamma_k\cap F_q=\varnothing,\quad\forall k,q.$$

飞行、服务与等待三类状态都是世界线的一部分,用同一条件约束。

### 4.2 空间约束向时间约束的解析投影

航段 i→j 的参数化:p(λ)=p_i+λ(p_j−p_i),t=s+λτ_ij(0≤λ≤1,s 为出发时刻)。
代入圆方程 ‖p(λ)−c_q‖²=R_q² 得二次方程 aλ²+bλ+c=0,求出进入/离开禁飞圆的参数
λ_in、λ_out,进而得到进入/离开时刻。航段与动态禁飞区冲突的充要条件为出发时刻落入
**禁止出发时间窗**

$$F_{ijq}=(a_q-\lambda_{out}\tau_{ij},\ b_q-\lambda_{in}\tau_{ij}).$$

对全部禁飞区取区间并集得 F_ij。空间信息(圆心、半径、航向、速度)全部投影到
F_ij 中,硬约束简化为 s ∉ F_ij,可直接查表。

### 4.3 动态航段代价

定义 τ̃_ij(s) 为时刻 s 出发完成航段 i→j 的最短合法时间:

$$\tilde\tau_{ij}(s)=\min\{\tau_{direct},\tau_{wait},\tau_{detour}\},$$

- 直飞:s ∉ F_ij 时的飞行时间;
- 等待:s 落在 F_ij 内时,推迟至最早合法出发时刻 s′ 后直飞,代价 (s′−s)+τ_ij;
- 绕行:沿"切线—圆弧—切线"路径绕过禁飞圆(圆外端点间的最短避障路径)。

两点补充:①等待位置本身也是硬约束——若等待点在生效禁飞圆内,须先转移到圆外悬停;
②服务阶段的 5 min 与等待阶段同样受时空约束检查。因此最终验证覆盖**飞行、服务、
等待**三类状态。

### 4.4 全局优化(ALNS)

以问题2 调度为初解,按 τ̃ 递推各机时刻(到达 = 出发 + τ̃;离开 = 到达 + 5),对候选
方案用**真实动态代价**评估,不可行方案直接排除。优化采用大邻域搜索:

1. 破坏:从当前方案中删除少量任务(最长路线任务、禁飞敏感航段邻近任务、随机任务、
   空间相近任务);
2. 修复:对每个被删任务枚举全部"无人机 × 插入位置",取词典序最优的合法插入;
3. 局部搜索:relocate / swap / 2-opt(段反转) / cross-exchange(跨机换尾);
4. 接受:词典序 (T_max, δ) 改进必收,否则按模拟退火概率接受。

**与"静态求解 + 事后修复"的本质区别**:静态距离目标无法感知禁飞区的时间属性,
会把"距离近但需长时间等待"的航段误判为廉价;事后修复又无权改变任务顺序。本模型
让搜索与最终考核使用同一套动态代价,优化方向与约束语义一致。实测:Case2 的
T_max 由 11.92 h 降至 10.97 h,Case3/4 在 T_max 不变的条件下 δ 由 0.55/0.30 h
压缩至 0.10/0.04 h。

### 4.5 独立验证

求解与验证独立实现。验证程序对每个航段按二次方程精确判交(无时间采样),对飞行、
服务、等待三类状态逐一复核,四个算例违例数均为 0。

## 6 主要亮点

1. **统一时空硬约束**:空间禁飞与时窗合成时空禁飞域,世界线判据 Γ∩F=∅ 同时约束
   飞行、服务、等待三类状态;
2. **解析投影**:二次方程求交把空间约束等价转化为航段禁止出发时间窗 F_ij,精确、
   无采样误差、可预计算;
3. **动态代价直接搜索**:以 τ̃_ij(s) 作为搜索中的真实代价,优于"静态求解 + 事后
   修复",有对照实验数据;
4. **理论性**:问题2 的单调性引理与二分搜索、δ 下界证书;问题1 的下界-构造证明结构;
5. **证据链完整**:求解与验证独立、全部零违例、六项敏感性分析、结果可复现。

## 7 诚实边界(论文表述口径)

- GLS 与 ALNS 均为启发式,T_max、δ 是"找到的最好可行解"(目标值上界),非全局最优;
- 问题1 的 Nmin:Case2 严格得证;Case1/3/4 为"下界 + 构造 + 求解证据";
- 多圆同时绕行未求全局最短路径(单圆切线绕行 + 全验证),作为局限说明;
- 假设:直线匀速飞行、开圆约定(边界接触不算进入)、多次巡检可连续完成。
