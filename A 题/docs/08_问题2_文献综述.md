## 2. 文献清单(分主题)

### 2.1 min-max VRP 与负载均衡(最对口)

1. Golden B L, Laporte G, Taillard É D. An adaptive memory heuristic for a class of
   vehicle routing problems with minmax objective[J]. Computers & Operations Research,
   1997, 24(5): 445-452. [已验证,zbMATH Zbl 0882.90031](https://zbmath.org/?q=an%3A0882.90031)
   - **与本题的关系**:min-max(而非 min-sum)VRP 的经典开山作,自适应记忆(adaptive memory)元启发式正是把"最长路线"作为目标、显式迭代"从最长路线中抽取任务重新插入"来压低 T_max 并间接均衡——与我们"把边界任务从 T_max 机搬到 T_min 机"的局部搜索思想同源。问题2 模型小节必引。

2. Carlsson J G, Ge D, Subramaniam A, Wu A, Ye Y. Solving min-max multi-depot
   vehicle routing problem[C]//Lectures on Global Optimization. 2009.
   [已验证,zbMATH Zbl 1177.90035](https://zbmath.org/?q=an%3A05589233);
   [Semantic Scholar 记录](https://www.semanticscholar.org/paper/Solving-Min-Max-Multi-Depot-Vehicle-Routing-Problem-Carlsson-Ge/15636f8eea916e8cfa30f85f5f4d159598fd7a5e)
   - **与本题的关系**:①提出 min-max 目标的 LP 松弛/对偶下界,可类比用于"makespan 下界证书";②提出用 min-max 与 min-sum 两个解作为**均衡度(最大/最小路线差)的上下界端点**——这正是"先求 T*(问题1),再在 T* 邻域内压 δ"这一策略的文献出处,建议直接引用支撑 4.1 节的词典序建模。

### 2.2 最大最小公平 / 均衡的理论根基

3. Bansal N, Sviridenko M. The Santa Claus problem[C]//Proceedings of the 38th ACM
   Symposium on Theory of Computing (STOC). 2006: 31-40. [已验证,zbMATH Zbl 1301.90057](https://zbmath.org/1301.90057#1)
   - **与本题的关系**:Santa Claus 问题 = 把异质资源分配给玩家,最大化最小所得,与"max T_min"完全同构。其"配置 LP + 舍入"框架说明:均衡问题难在**异质性**(任务代价差异巨大),不能靠均分数量;阈值法(给每个玩家下界 L、判定可行性)是该问题域的标准思考方式。用于 4.2 节给"下界 L 网格/二分"提供理论定位。

4. Asadpour A, Feige U, Saberi A. Santa Claus meets hypergraph matchings[C]//APPROX-RANDOM. 2008.
   [已验证,zbMATH Zbl 1159.68663](https://zbmath.org/1159.68663#1)
   - 可选引用;若论文讨论"均衡问题的一般近似性",可提一句。

### 2.3 双目标求解范式:ε-约束 / 词典序

5. Bérubé J F, Gendreau M, Potvin J Y. An exact ε-constraint method for bi-objective
   combinatorial optimization problems: Application to the traveling salesman problem
   with profits[J]. European Journal of Operational Research, 2009, 194(2): 530-543.
   [已验证,zbMATH Zbl 1179.90274](https://zbmath.org/05370055#1);
   [researchr 记录](https://researchr.org/publication/BerubeGP09/bibliographies)
   - **与本题的关系**:双目标组合优化 ε-约束方法的权威实现——逐次固定一个目标为约束、求另一目标最优,并按"每次新获的 Pareto 点收紧约束"迭代。我们的"ε=0/1%/2% 分层 + 层内最小化 δ"正是其离散版本。算法小节必引。

6. Jozefowiez N, Semet F, Talbi E G. Multi-objective vehicle routing problems[J].
   European Journal of Operational Research, 2008, 189(2): 293-309. [凭记忆,经典综述]
   - **与本题的关系**:双目标 VRP 的综述,系统比较加权和、词典序、ε-约束、Pareto 进化算法;其中"加权和取不到非凸 Pareto 前沿,ε-约束可以"的结论可直接用来论证我们为什么不采用加权目标。

7. 近期 matheuristic: A matheuristic augmented ε-constraint framework for a bi-objective
   Multi-Depot Cumulative Capacitated Vehicle Routing Problem[J/OL]. European Journal of
   Operational Research, 2026. [已验证]
   [ScienceDirect](https://www.sciencedirect.com/science/article/pii/S037722172600576X)
   - **与本题的关系**:2026 年最新文献,展示"词典序求端点 + 增强 ε-约束 + matheuristic"的现代做法,说明该范式仍是当前主流;引它可提升论文文献时效性(摘要提到其 lexicographic 初始化和 ε 值的选取方式)。

### 2.4 聚类-均衡划分路线(备选算法 R4 的支撑)

8. Balanced K-Means Algorithm for Partitioning Areas in Large-Scale Vehicle Routing
   Problem[C]//Third International Symposium on Intelligent Information Technology
   Application (IITA). 2009. [已验证,IEEE Xplore](https://ieeexplore.ieee.org/abstract/document/5369502)

## 4. 写作要点(结合文献共识)

1. **文献共识**:此类问题的主流求解有三条线——(a) 精确/近精确的 ε-约束或分支定界 [5];(b) 单目标元启发式(自适应记忆、GLS 等)[1];(c) 进化多目标(NSGA-II 等)[11]。本文选择 (b)+ε-约束混合,理由是:问题规模(M≤182)下精确方法不现实,而进化多目标调参成本高、解不可复现性较强。
2. **可引用的理论表述**:max-min 均衡是 Santa Claus 型问题 [3];"阈值 + 二分可行性判定"是瓶颈/公平问题的标准范式;δ 的下界证书 (NT_max-S)/(N-1) 属于 min-max 解质量界这一类文献思路 [2]。
3. **如实声明**:文献 [1][2] 均为启发式/松弛方法,min-max VRP 无 PTAS(APX-hard),故论文中"δ 已达最小"应表述为"在 ε 层内、相对搜索网格的最优",并给出下界证书的间隙。
