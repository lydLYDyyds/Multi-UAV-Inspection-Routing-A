# 论文骨架(五校联赛 A 题;数字已填充定稿)

## 标题
低空经济背景下多无人机协同巡检路径优化:下界驱动的 min-makespan 调度、负载均衡与禁飞区规避

## 摘要(定稿草稿,约 500 字)

针对低空经济背景下多无人机协同巡检的路径优化问题,本文围绕"9 小时内完成任务、均衡工作负载、规避动态禁飞区"三个层次,建立了逐层递进的调度模型。

针对问题一,将各巡检等级展开为虚拟任务节点,以总工时下界分析与构造性调度共同确定最小无人机数,四个算例分别为 4、2、4、4 架;进而以最小化最长工作时间 T_max 为目标,采用引导式局部搜索求解多旅行商调度,得到最短完成时间 7.883、7.178、8.373、8.020 h。

针对问题二,建立词典序双目标模型(先最小 T_max,再最小负载差 δ=T_max−T_min),利用可行域关于各机工作时长下界 L 的单调性,通过 ε-约束与二分搜索在完成时间不恶化的前提下最大化 L,将四个算例的负载差压缩至 0.077、0.002、0.029、0.030 h,并给出 δ 的数学下界证书。

针对问题三,将动态圆形禁飞区建模为时空禁飞域,对航段直线轨迹解析求交,把"空间障碍 + 时间窗"耦合约束等价投影为航段禁止出发时间窗;在此基础上构造直飞、等待(含圆外悬停)与切线绕行三类候选的动态航段代价,并以飞行、服务、等待三类状态的统一时空硬约束进行验证,采用大邻域搜索在真实动态代价上直接优化。四个算例的完成时间为 7.840、10.969、8.427、8.085 h,负载差为 0.077、0.038、0.103、0.039 h,全部方案经独立解析验证违例数为零。

本模型无需时间采样,求解与验证相互独立,并通过六项敏感性分析检验了主要假设的稳健性。

**关键词**:多无人机巡检;负载均衡;动态禁飞区;禁止出发时间窗;大邻域搜索
